# Kochfreunde

## ⬇ Installieren-Knopf (2026-10-18)

Klaus: *„Den Installieren-Button überall fest einbauen … Wenn es kein Einstellungsfeld gibt, dann oben ins Menü."*
Kochfreunde hat keine Einstellungen (der versteckte Bereich bleibt bewusst ohne Knopf), deshalb steht ⬇ rund in der
Kopfleiste vor 📸. `assets/installieren.js` ist byte-1:1 aus Sage-Protokol (SHA-256 `e0644084…c3c3`) — dort pflegen,
hier neu kopieren. Als installierte App verschwindet er. Bis 380 px Breite sind die drei Rundknöpfe 36 px, damit die
Kopfleiste bei 360 px einzeilig bleibt. Im Vorrat, Cache `kochfreunde-v2`. ⚠ Am Tablet/Handy nicht gemessen.
